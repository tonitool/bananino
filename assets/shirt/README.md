# Collaboration artwork

One PNG per brand, named by the `logo` field of its entry in
[shirts.js](../../src/renderer/scene/shirts.js). Transparent background, square-ish, at
least 512px on its long edge. `scripts/build-renderer.mjs` copies whatever is in this
folder, so a new collaboration is a file and a registry entry — never a build edit.

**These files are not covered by this repository's licence.** Every logo here is the
property of the brand it belongs to and is included with their permission, for use on
Bananino's shirt and nothing else. Removing a brand means deleting its PNG and its registry
entry; nothing else refers to it.

The folder is empty today. The shirt ships blank.
